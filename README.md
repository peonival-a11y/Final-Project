#  The project that I have made is a simple cat platformer game, but it implemented a coin that is a ball of yarn for the cat to get while exploring the level. The files in the repository are combined, and I got help from a video that inspired me with the idea. I am really proud of how the pixel art of the cat and the yarn came out since it was a bit tricky to get the animation flowing right due to it being small pixels. But one of the few things I wished I had done differently or added was maybe experimenting with what else I could add, like obstacles with traps or monsters lurking to interact with the cat. As much as the background was temporary it I did end up settling for it because it matched with the bright colors of the color scheme it had in the end. I hope to improve in making code cleaner but it was a great experience learning how to do this simple platformer game
